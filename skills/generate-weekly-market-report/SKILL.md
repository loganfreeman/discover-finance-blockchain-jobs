# Generate Weekly Market Report

Use this skill when a user wants a current market report for software engineering hiring in finance, fintech, trading, crypto, DeFi, or blockchain.

The report should help the user decide where to focus this week. Current hiring data changes quickly: use fresh web research when available, cite sources, and include the report date. If web access is unavailable, produce a report only from user-provided data and label it accordingly.

## Inputs

Useful inputs:

- Target role family.
- Industry focus.
- Region and remote preference.
- Seniority.
- Skills or stack.
- Number of companies or roles to sample.
- Whether to include interview prep, compensation signals, or skill trends.

## Report Scope

Prefer a practical weekly scan over a broad essay. Include:

- Hiring summary.
- Companies with current relevant engineering roles.
- Role and skill trends.
- Notable positive and risk signals.
- Suggested application targets.
- Resume keywords to emphasize this week.
- Watchlist companies to monitor.

Use `references/domain-taxonomy.md` for consistent category labels.

## Output

Follow `templates/report.md`. Include source links and retrieval dates. Make clear when a conclusion is an inference from observed postings rather than a confirmed company statement.
